<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → GitHub Pages | Build artifacts upload — all files in `./out/` become public; no secrets should exist in build output |
| Developer machine → GitHub repo | `git push main` triggers deployment; branch protection not configured (single developer) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `next.config.ts` | mitigate | `next.config.ts` contains no secrets — basePath is public info; GITHUB_TOKEN used by deploy-pages is scoped to this run automatically |
| T-01-02 | Tampering | npm dependencies (install step) | accept | All packages verified in RESEARCH.md Package Legitimacy Audit — all have [VERIFIED] disposition; slopcheck confirmed no suspicious postinstall scripts |
| T-01-03 | Elevation of Privilege | GitHub Actions permissions | mitigate | Workflow uses minimum permissions: `contents: read`, `pages: write`, `id-token: write`. No `contents: write` (no push-back from CI). `cancel-in-progress: false` prevents race conditions on concurrent runs |
| T-01-04 | Tampering | Supply chain (GitHub Actions) | mitigate | All actions pinned to major version tags (v4, v5) from official GitHub/actions org. No third-party action runners used |
| T-01-05 | Information Disclosure | `./out/` static build artifacts | accept | Static site is intentionally public. No secrets, API keys, or tokens in Phase 1 code. Bot token is Phase 3 and stays in GitHub Secrets only |
| T-01-SC | Tampering | npm install (supply chain) | accept | Package Legitimacy Audit in RESEARCH.md shows all packages [VERIFIED] with legitimate source repos; no [ASSUMED] or [SUS] packages — no blocking checkpoint required |
</threat_model>
