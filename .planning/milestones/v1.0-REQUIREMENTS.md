# Requirements Archive: v1.0 MVP

**Archived:** 2026-05-20
**Milestone:** v1.0 MVP
**Core Value:** A scout or coach visiting the site immediately understands who this player is, what they can do, and how to contact them — within seconds of landing on the page.

---

## v1 Requirements — Completion Status

### Foundation & Infrastructure

- [x] **FOUND-01**: Site builds as a fully static export (`output: 'export'`) and deploys to GitHub Pages via GitHub Actions on every push to `main` — ✓ Complete (Phase 1)
- [x] **FOUND-02**: All assets load correctly on GitHub Pages (basePath, assetPrefix, trailingSlash, and .nojekyll configured correctly) — ✓ Complete (Phase 1)
- [x] **FOUND-03**: Next.js App Router project scaffolded with TypeScript, SCSS Modules, and `app/[lang]/` locale routing structure — ✓ Complete (Phase 1)
- [x] **FOUND-04**: All images pre-optimized as WebP with correct dimensions; `next/image` configured with `unoptimized: true` — ✓ Complete (Phase 1)

### Visual Design System

- [x] **VIS-01**: CSS custom property token system defined for colors, spacing, and typography — supports light and dark themes via `data-theme` attribute — ✓ Complete (Phase 1)
- [x] **VIS-02**: User can toggle between light and dark themes; preference persists across sessions with no flash on page load (FOUC prevented) — ✓ Complete (Phase 1)
- [x] **VIS-03**: Premium typography scale implemented using Next.js font optimization (self-hosted Google Fonts) with both Latin and Cyrillic subsets — ✓ Complete (Phase 1)
- [x] **VIS-04**: Site is fully mobile-responsive across all sections (375px to 1440px+) — ✓ Complete (Phase 1)
- [x] **VIS-05**: Smooth inertia-based scrolling via Lenis; GSAP ScrollTrigger integrated with Lenis scroll proxy — ✓ Complete (Phase 1)

### Homepage & Hero

- [x] **HOME-01**: Visitor lands on a cinematic hero section with the player's name, position, and a high-impact full-screen visual — ✓ Complete (Phase 2)
- [x] **HOME-02**: Hero section includes scroll-triggered entrance animations (text reveal, image parallax) using GSAP ScrollTrigger — ✓ Complete (Phase 2)
- [x] **HOME-03**: Hero section includes a clear Call-to-Action button directing scouts to the contact section — ✓ Complete (Phase 2)
- [x] **HOME-04**: Page sections transition smoothly as user scrolls using Framer Motion and GSAP animations; page feels cinematic not static — ✓ Complete (Phase 2)

### Player Profile

- [x] **PLAYER-01**: Visitor can view the player's full profile: full name, position, working foot, nationality, date of birth, and current club — ✓ Complete (Phase 2)
- [ ] **PLAYER-02**: Visitor can view a high-quality real photo of the player — ⚠ Deferred (structural slot built, real photo is a content update — deferred to post-v1.0)
- [x] **PLAYER-03**: Visitor can view key player statistics or attributes (configurable from `content/player.ts`) — ✓ Complete (Phase 2)
- [x] **PLAYER-04**: Player information section tells the player's story through imagery and short narrative text — ✓ Complete (Phase 2)

### Media System

- [x] **MEDIA-01**: Visitor can watch embedded YouTube highlight videos using a lite-embed pattern (thumbnail shown first, iframe loads on click) — ✓ Complete (Phase 3)
- [x] **MEDIA-02**: Visitor can browse a photo gallery of training and match images with a lightbox viewer (zoom, navigation, fullscreen) — ✓ Complete (Phase 3)
- [x] **MEDIA-03**: Video and gallery sections do not block page load or hurt Lighthouse performance score (lazy loading enforced) — ✓ Complete (Phase 3)

### Supporting Content Sections

- [x] **SECT-01**: Visitor can view a trophies / achievements section displaying the player's career honors — ✓ Complete (Phase 2)
- [x] **SECT-02**: Visitor can view information about the player's current club — ✓ Complete (Phase 2)
- [x] **SECT-03**: Visitor can view a team section (player's current teammates or squad context) — ✓ Complete (Phase 2)

### Contact System

- [x] **CONTACT-01**: Visitor can submit a contact form with name, phone (optional), and message — ✓ Complete (Phase 3) *Note: email field removed per user request; name + phone + message*
- [x] **CONTACT-02**: Successful form submission triggers a Telegram notification to the player/agent via GitHub Actions + Telegram Bot API — ✓ Complete (Phase 3, confirmed live)
- [x] **CONTACT-03**: Contact form includes spam protection: honeypot hidden field and submission time check — ✓ Complete (Phase 3)
- [x] **CONTACT-04**: Bot token and chat ID are stored in GitHub Secrets only — never exposed in client-side code — ✓ Complete (Phase 3)

### Bilingual Support (UA / EN)

- [x] **I18N-01**: Site is available in both Ukrainian (UA) and English (EN) at separate URL paths (`/ua/` and `/en/`) — ✓ Complete (Phase 4)
- [x] **I18N-02**: Visitor can switch between UA and EN languages via a language toggle; preference persists across sessions — ✓ Complete (Phase 4)
- [x] **I18N-03**: All UI strings, section titles, CTA copy, and player bio text are defined in locale dictionary files — ✓ Complete (Phase 4)
- [x] **I18N-04**: Both locale versions are pre-rendered as static HTML at build time (zero runtime i18n overhead) — ✓ Complete (Phase 4)
