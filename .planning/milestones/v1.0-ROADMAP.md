# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-20
**Phases:** 1–4
**Total Plans:** 14

## Overview

Four phases took Future Legend from a blank repo to a fully bilingual, cinematic football player portfolio deployed on GitHub Pages. Phase 1 locked in the static export config, CI/CD pipeline, and design system. Phase 2 built every content section with animations, delivering the complete scout-facing experience. Phase 3 added the media system and wired up the Telegram contact pipeline. Phase 4 completed the UA/EN bilingual experience with pre-rendered locale routes and a persistent language switcher.

## Milestone Summary

**Key Decisions:**

- Next.js static export with `app/[lang]/` dynamic segment — Next.js built-in i18n config is incompatible with static export; manual locale routing used instead
- GSAP must run inside `useGSAP()` in `'use client'` components — prevents "window is not defined" during static build prerendering
- basePath and assetPrefix must be configured before any CI run — missing these causes blank page with all assets 404ing
- Framer Motion owns mount/unmount & hover; GSAP owns scroll-triggered sequences — never animate the same element with both
- GitHub workflow_dispatch returns 204 — success check is `response.ok`, never `=== 202`
- NEXT_PUBLIC_GH_PAT baked at build time — editing token permissions regenerates value, requires secret update + redeploy
- Contact form email field removed per user request; name min-3-char validation + phone +380 mask added
- D-12 Option A — translatable fields removed entirely from player.ts interfaces (not kept as optional)
- getDictionary uses dynamic import() (not fs.readFile) — required for static export compatibility
- Root redirect localStorage 'locale' whitelisted to 'ua'|'en', defaults to 'ua' for security
- LanguageSwitcher mounted guard replicates ThemeToggle.tsx pattern — prevents hydration mismatch
- TrophiesSection index-based zip — dict.trophies.items[i] for name/competition, trophy.year from player data

**Known Gaps at Close:**

- PLAYER-02: Real player photo (deferred — structural slot built in HeroSection, real asset is a content update)

**Technical Debt Incurred:**
