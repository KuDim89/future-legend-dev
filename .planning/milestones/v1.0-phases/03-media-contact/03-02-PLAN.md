<objective>
Build the highlights vertical slice: a responsive grid of video cards where each card shows a static YouTube thumbnail on load and swaps to a playing `<YouTube>` iframe only after the user clicks. After this plan, a visitor can watch any highlight clip on demand with zero iframes loaded at initial page render (MEDIA-01 + MEDIA-03).

Purpose: This is the lite-embed performance pattern — the single most important correctness detail in the media system. `react-youtube` renders a full iframe on mount, so the iframe MUST be gated behind an `isPlaying` state guard.
Output: `components/ui/VideoCard.tsx` (+ `.module.scss`), `components/sections/HighlightsSection.tsx` (+ `.module.scss`). page.tsx wiring is deferred to plan 03-04.
</objective>

| YouTube thumbnail URL → external img.youtube.com | External image request constructed from videoId |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

No iframe and no youtube.com/iframe_api request before user click (MEDIA-03). Verified by acceptance criterion that `<YouTube` only appears in the truthy branch. |
| T-03-04 | Tampering (XSS) | thumbnail src / title rendering | accept | `videoId` and `title` come from build-time content/videos.ts (trusted, developer-authored), interpolated into a string URL and rendered as React text/attribute nodes — no `dangerouslySetInnerHTML`. No untrusted input path in this plan. |
